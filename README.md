# Competitive Programming

競技プログラミングの学習記録として、解いた問題の C++ による解答と、アルゴリズム・データ構造のライブラリをまとめています。

主に [AtCoder](https://atcoder.jp/) の AtCoder Beginner Contest、競プロ典型 90 問、競技プログラミングの鉄則に取り組んでいます。

## Contents

| ディレクトリ | 内容 |
| --- | --- |
| `ABC/` | AtCoder Beginner Contest の解答 |
| `Typical90/` | 競プロ典型 90 問の解答 |
| `Tessoku/` | 競技プログラミングの鉄則の解答 |
| `Algorithm/` | 文字列、グラフ、数学などのアルゴリズム |
| `DataStructure/` | Union-Find、Segment Tree などのデータ構造 |

このほかにも、AtCoder Regular Contest などのコンテストや練習問題の解答を収録しています。

## Usage

各解答は、基本的に単独でコンパイル・実行できる C++ ファイルです。ターミナルでは、たとえば次のように実行します。

```bash
g++ -std=c++17 -O2 ABC/ABC400-499/ABC470/A.cpp -o main
./main
```

## Notes

- 解答はコンテスト参加時の提出コードや、その後の学習・復習で作成したコードを含みます。
- ライブラリは、自分の競技プログラミングでの利用を目的として実装しています。
- すべてのコードについて、最適性や動作を保証するものではありません。
